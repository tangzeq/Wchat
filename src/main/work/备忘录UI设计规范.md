# 备忘录UI设计规范

## 设计原则
- **分离原则**：UI设计与业务逻辑分离
- **可视化设计**：使用.form文件进行可视化UI设计
- **代码职责**：JAVA代码只负责业务交互逻辑

## UI设计规范

### 1. 面板结构
- **memoPanel**：主面板，使用GridLayoutManager
- **topPanel**：顶部面板，包含搜索框和添加按钮
- **scrollPane**：滚动面板，用于显示任务卡片
- **memoContainer**：任务卡片容器
- **bottomPanel**：底部面板，显示统计信息

### 2. 组件设置
- **搜索框**：JTextField，提示文本"搜索任务..."
- **添加按钮**：JButton，文本"+ 添加"
- **任务卡片**：JPanel，固定大小(200, 150)
- **统计标签**：JLabel，显示待办任务和今日完成数量

### 3. 布局设置
- **主面板**：GridLayoutManager，3行1列
- **顶部面板**：GridLayoutManager，1行2列
- **底部面板**：GridLayoutManager，1行2列
- **任务容器**：FlowLayout，左对齐，水平间距10，垂直间距15

## 代码规范

### 1. JAVA代码职责
- **业务逻辑**：处理任务的添加、编辑、删除、标记完成等操作
- **数据管理**：与MemoService交互，处理数据的存储和加载
- **事件处理**：处理按钮点击、搜索框输入等事件
- **响应式设计**：处理面板大小变化，更新布局

### 2. 禁止在JAVA代码中设置的内容
- **面板布局**：布局设置应在.form文件中完成
- **组件大小**：组件大小应在.form文件中设置
- **组件间距**：间距设置应在.form文件中完成
- **组件位置**：组件位置应在.form文件中设置

## 实现步骤
1. 在.form文件中设置所有UI组件和布局
2. 在JAVA代码中实现业务逻辑和事件处理
3. 确保UI设置与代码逻辑分离

## 最佳实践
- 使用IntelliJ IDEA的GUI Designer工具编辑.form文件
- 避免在JAVA代码中硬编码UI设置
- 保持代码整洁，只关注业务逻辑
- 定期检查UI设计与代码逻辑的分离情况
