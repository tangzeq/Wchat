# 备忘录功能设计文档

## 1. 功能概述

备忘录是一个生活记录提醒系统，帮助用户管理日常任务和重要事项。通过分类管理、定时提醒和视觉化时间排序，让生活更有条理。

## 2. 核心功能

### 2.1 记录管理
- **创建记录**：支持添加内容、卡片颜色、文字颜色、提醒时间、重复规则等
- **编辑记录**：随时修改记录的任何信息
- **删除记录**：支持单条删除
- **完成状态**：支持勾选标记完成，完成后可取消完成状态

### 2.2 提醒系统
- **定时提醒**：设置具体的提醒时间
- **重复提醒**：支持每天、每周、每月等重复规则
- **提醒方式**：IDE内通知、系统通知

### 2.3 界面设计
- **卡片式布局**：每条记录以小卡片形式展示
- **时间排序**：按提醒时间自动排序，越接近的越靠前
- **视觉区分**：卡片颜色和文字颜色可自定义
- **状态标识**：待办/完成状态有明显视觉区分
- **搜索过滤**：支持按关键词搜索

## 4. 技术实现

### 4.1 数据存储
- **存储位置**：使用文件系统存储数据，位于用户目录下的 `.wchat-memo` 文件夹
- **数据结构**：
  - 记录数据：文本文件格式，使用管道符分隔，包含id、内容、卡片颜色、文字颜色、提醒时间、重复规则、完成状态等字段
- **数据同步**：本地存储，支持自动保存

### 4.2 提醒实现
- **定时任务**：利用IDE的定时任务系统触发提醒
- **通知系统**：调用系统通知API发送提醒，显示包含操作选项的对话框
- **提醒队列**：维护待提醒任务队列，确保及时触发
- **用户操作处理**：处理用户在提醒时的选择（标记完成、取消任务、重新指定提醒时间）

### 4.3 界面实现
- **技术选型**：使用Swing构建卡片式界面，采用IntelliJ IDEA表单设计器（.form文件）
- **组件设计**：
  - 主面板：`MemoPanel.java` 和 `MemoPanel.form`
  - 添加任务对话框：`AddMemoDialog.java` 和 `AddMemoDialog.form`
- **交互设计**：
  - 键盘快捷键：支持Enter键快速确认添加
  - 智能默认值：提醒时间默认设置为当前时间
  - 颜色预览功能：实时显示所选卡片颜色和文字颜色的组合效果
  - 颜色选择器：颜料板形式的颜色选择，点击即可切换颜色
  - 横排布局：卡片横排展示，自适应布局，自动换行
  - 响应式设计：根据窗口大小自动调整卡片排列和大小
- **布局优化**：
  - 卡片布局：任务内容占据卡片80%的空间，使用BorderLayout实现
  - 弹框布局：设置合适的最小和最大尺寸，确保内容完全展示
  - 字体设置：移除所有字体编码设置，使用系统默认字体
  - 空间分配：合理分配卡片内部空间，确保内容为主体
  - 卡片排列：卡片之间无间隙，紧密排列，使用FlowLayout(FlowLayout.LEFT, 0, 0)实现

### 4.4 性能优化
- **数据缓存**：使用内存缓存提高数据加载速度
- **懒加载**：大量记录时采用分页加载策略
- **异步处理**：提醒检查等操作异步执行，避免阻塞UI

## 6. 核心流程

### 6.1 添加备忘录流程
1. 用户点击"添加"按钮
2. 弹出添加任务对话框
3. 填写任务内容（必填）
4. 选择卡片颜色和文字颜色
5. 设置提醒时间和重复规则
6. 点击"保存"按钮
7. 系统保存数据并更新界面

### 6.2 提醒流程
1. 系统定时检查待提醒任务
2. 发现到达提醒时间的任务
3. 触发通知，显示提醒对话框
4. 用户收到提醒，可选择以下操作：
   - 标记任务为完成
   - 取消任务
   - 重新指定提醒时间
5. 系统根据用户选择执行相应操作

### 6.3 完成任务流程
1. 用户点击卡片上的"完成"按钮
2. 系统更新任务状态
3. 界面更新，任务卡片状态变化

## 9. 技术风险与应对

### 9.1 风险点
- **性能问题**：大量记录时可能导致界面卡顿
- **提醒可靠性**：IDE关闭时提醒可能无法触发
- **数据安全**：本地存储数据可能丢失

### 9.2 应对措施
- **性能优化**：采用分页加载和异步处理
- **提醒机制**：结合系统定时任务和IDE启动时检查
- **数据备份**：定期自动备份和手动导出功能
